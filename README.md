# 淘宝图片助手（Windows）

## 安装与运行

1. 安装 Python 3.10 或更新版本，并在安装时启用 Python Launcher（`py` 命令）。
2. 双击 `setup.bat` 安装依赖并校验 YuNet 人脸模型和约 3.6 MB 的 NanoDet 主体检测模型；运行时需要 Microsoft Edge。安装未完整结束时，启动脚本会停止并提示，不会继续打开一个缺依赖的程序。
3. 双击 `run.bat` 或 `run_web.bat`，程序会启动本机服务并自动打开新版界面。所有淘宝登录、下载和图片处理仍在本机完成；关闭助手窗口后服务会自动退出，下载处理中会等任务完成后退出。也可以点界面右上角“退出助手”。

服务只监听本机地址，其他设备无法访问。淘宝登录、下载和图片处理都在本机完成。点击右上角“退出助手”会停止服务和程序；浏览器不会自动关闭标签页，页面会提示退出状态，请手动关闭标签页。

如果想生成免安装 Python 的 Windows 单文件程序，在 Windows 上双击 `build_exe.bat`。完成后运行 `dist/淘宝图片助手.exe`，它会自动打开新版界面并在后台运行本机服务；关闭界面窗口会自动退出服务，下载处理中会等任务完成。程序使用电脑上已安装的 Microsoft Edge，不再附带 Chromium。

也可以从 GitHub 下载构建好的程序：进入仓库 Actions，打开最新成功的“Build Windows EXE”运行，在 Artifacts 中下载 `淘宝图片助手-Windows-x64` 并解压，运行其中的 `淘宝图片助手.exe`。每次推送到 `main` 的更新都会自动构建；源码仓库也提供手动运行入口。

## 使用

1. 粘贴淘宝商品链接，点“打开商品页”。
2. 在弹出的 Microsoft Edge 窗口中登录淘宝账号并确认打开的是目标商品页。扫描和下载前会检查淘宝登录标记（`unb` 或 `cookie17`）；未检测到标记时会停止操作。程序不记录 Cookie 值或账号信息。标记过期时仍可能被淘宝拒绝，具体状态会记入失败日志。
3. 单个商品：回到助手点“扫描图片”，可在列表中把图片类型改为主图或详情图，再点“下载并处理”。
4. 批量处理：点“批量下载”，把多个淘宝或天猫链接逐行粘贴后开始。程序按顺序打开商品页、扫描主图和详情图并下载；个别商品失败时会写入该商品文件夹的失败记录，再继续下一个。扫描不完整时会在批量完成摘要中列出提示。
5. 每个商品在所选目录下创建一个以商品标题命名的文件夹；原图保存在“下载原图”，处理结果按规格分开放在“处理后/主图_900x1200”、“处理后/主图_1200x1200”和“处理后/详情图_750px”。主图分别按 900×1200 和 1200×1200 的比例裁切到指定尺寸，优先围绕识别到的人物或商品主体居中；没有识别结果时从画面中心裁切，不加留白、不拉伸。详情图等比缩放到宽 750 像素，并在底部增加 15 像素白边。图片统一保存为 JPG；原本为 PNG 或带透明背景的图片保存为 PNG。同名商品或重复下载会自动添加序号，不覆盖已有文件。

如果有图片下载失败，本次文件夹中会生成“下载失败记录.txt”，记录失败阶段、HTTP 状态、返回类型、错误类型和图片地址。图片会按实际文件内容解码，因此 CDN 返回通用二进制类型时不会被误判；真正无法解码的响应会写入失败日志。程序只跟随淘宝图片域名的 HTTPS 跳转，并释放已处理的网络响应，避免长批次持续占用内存。

打开商品页、登录检查、扫描或页面诊断发生异常时，错误类型和具体原因会追加到用户目录下 `.taobao_image_helper/运行日志.txt`；图片下载失败仍记录在商品文件夹内的“下载失败记录.txt”。

程序会在单独的 Edge 配置中记住登录状态。镜像是左右翻转。扫描会限定在商品主图画廊和详情内容区；同一张图的多个清晰度版本会优先选尺寸较大的链接。无法识别这些区域时会提示，不会按整页位置猜图片类型。若淘宝改版导致识别失败，“页面诊断”可生成只含页面容器标签、类名、图片数量和尺寸的 JSON。报告不包含 Cookie、商品标题或图片地址。图片类型可以手动修正。主图主体使用 OpenCV Zoo 的 NanoDet COCO 目标检测模型，能优先围绕人物和常见物体裁切；时装、特殊商品或模型漏检时会回退到中心裁切，建议检查裁切结果。人脸识别使用 [OpenCV Zoo YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) 模型；马赛克会扩展到人脸框周边并使用更大的像素块。小脸、侧脸或遮挡的人脸仍可能漏检，建议抽查处理结果。YuNet 的 MIT 许可文本位于 `models/LICENSE`，NanoDet 的 Apache 2.0 许可位于 `models/NANODET_LICENSE`。

## 文件

- `app.py`：图片扫描、下载、人脸处理和浏览器工作线程
- `requirements.txt`：运行依赖
- `setup.bat`：首次安装
- `run.bat`：启动新版界面
- `run_web.bat`：启动本机网页界面
- `web_app.py`、`index.html`：本机网页和服务
- `build_exe.bat`：在 Windows 上生成 exe 发布目录

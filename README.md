# 淘宝图片助手

Windows 桌面工具：从淘宝或天猫商品页扫描并下载主图、详情图，可选左右镜像和人脸马赛克。浏览器登录、下载和图片处理都在本机完成。

## 下载 Windows 程序

打开本仓库的 **Actions**，进入最新成功的 **Build Windows EXE** 运行，在 Artifacts 下载 `taobao-image-helper-windows`。解压后双击 `淘宝图片助手/淘宝图片助手.exe`；请保留解压出的整个文件夹，其中包含浏览器运行文件。

## 从源码运行或构建

查看 [`taobao-image-helper/README.md`](taobao-image-helper/README.md)。Windows 用户也可以双击 `setup.bat` 安装依赖，再双击 `run.bat` 运行；`build_exe.bat` 会生成可分发的程序文件夹。

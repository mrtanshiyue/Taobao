# 淘宝图片助手

Windows 桌面工具：登录淘宝后扫描商品主图和详情图，按需左右镜像并给人脸打马赛克。下载和图片处理都在本机完成。

## 下载 Windows 程序

打开 **Actions**，进入最新成功的 **Build Windows EXE** 运行，在 Artifacts 下载 `taobao-image-helper-windows` 并解压，运行 `淘宝图片助手.exe`。电脑需要安装 Microsoft Edge；程序使用单文件 EXE，不附带浏览器。

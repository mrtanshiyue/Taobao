# 淘宝图片助手（Windows）

## 安装与运行

1. 安装 Python 3.10 或更新版本，并在安装时启用 Python Launcher（`py` 命令）。
2. 双击 `setup.bat` 安装依赖；运行时需要 Microsoft Edge。
3. 想用网页界面，双击 `run_web.bat`；程序会启动本地服务并自动打开浏览器。想用桌面窗口则双击 `run.bat`。

网页模式只监听本机地址，其他设备无法访问；关闭启动窗口即可停止服务。淘宝登录、下载和图片处理都在本机完成。

如果想生成免安装 Python 的 Windows 单文件程序，在 Windows 上双击 `build_exe.bat`。完成后运行 `dist/淘宝图片助手.exe`。程序使用电脑上已安装的 Microsoft Edge，不再附带 Chromium。

也可以在 GitHub 仓库的 Actions 页面下载自动构建的 Windows 压缩包：打开最新成功的“Build Windows EXE”运行，在 Artifacts 中下载并解压，双击里面的 `淘宝图片助手.exe`。

## 使用

1. 粘贴淘宝商品链接，点“打开商品页”。
2. 在弹出的 Microsoft Edge 窗口中登录淘宝账号并确认打开的是目标商品页。扫描和下载前会检查淘宝登录标记（`unb` 或 `cookie17`）；未检测到标记时会停止操作。程序不记录 Cookie 值或账号信息。标记过期时仍可能被淘宝拒绝，具体状态会记入失败日志。
3. 单个商品：回到助手点“扫描图片”，可在列表中把图片类型改为主图或详情图，再点“下载并处理”。
4. 批量处理：点“批量下载”，把多个淘宝或天猫链接逐行粘贴后开始。程序按顺序打开商品页、扫描主图和详情图并下载；个别商品失败时会写入该商品文件夹的失败记录，再继续下一个。
5. 每个商品在所选目录下创建一个以商品标题命名的文件夹；图片保存在“下载原图”，处理结果保存在“处理后”。图片统一保存为 JPG；原本为 PNG 或带透明背景的图片保存为 PNG。同名商品或重复下载会自动添加序号，不覆盖已有文件。

如果有图片下载失败，本次文件夹中会生成“下载失败记录.txt”，记录失败阶段、HTTP 状态、返回类型、错误类型和图片地址。程序会使用当前商品页地址作为图片请求来源；可根据日志区分网络请求、淘宝 CDN 响应、图片格式和本地处理错误。

程序会在单独的 Edge 配置中记住登录状态。镜像是左右翻转。扫描会限定在商品主图画廊和详情内容区；无法识别这些区域时会提示，不会按整页位置猜图片类型。若淘宝改版导致识别失败，桌面程序的“导出页面诊断”可生成只含页面容器标签、类名、图片数量和尺寸的 JSON。报告不包含 Cookie、商品标题或图片地址。图片类型可以手动修正。人脸识别使用 OpenCV 内置分类器，并提高了检测阈值以减少手部、衣服等误判；较小、侧脸或遮挡的人脸仍可能漏检，建议检查处理结果。

## 文件

- `app.py`：桌面程序
- `requirements.txt`：运行依赖
- `setup.bat`：首次安装
- `run.bat`：启动程序
- `run_web.bat`：启动本机网页界面
- `web_app.py`、`index.html`：本机网页和服务
- `build_exe.bat`：在 Windows 上生成 exe 发布目录
